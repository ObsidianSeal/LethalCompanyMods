## HOW TO INSTALL THE MODS

last updated: `2025/12/29`

0. if you don&rsquo;t know where your `Lethal Company` folder is, go to **Steam > Library > Lethal Company (right click) > Installed Files > Browse**
1. copy everything (4 items) within `BepInEx-BepInExPack-5.4.2305\BepInExPack` into the `Lethal Company` folder
     - `BepInEx`
     - `.doorstop_version`
     - `doorstop_config.ini`
     - `winhttp.dll`
2. make a folder in the (just pasted) `BepInEx` folder called `plugins`
3. paste the other (9) mod folders into this new `plugins` folder

you&rsquo;re also welcome to install the mods (from the list below) manually (one-by-one) through a mod manager

## INFORMATION & RECOMMENDATIONS

last updated: `2024/12/29`

- make sure your scroll (inventory) controls are in the direction you want them
- remove all the **More Emotes** keybinds (for individual emotes, not the wheel)
- DO NOT TOUCH THE CONSOLE (it is supposed to be there the entire time)
- to make **Boombox Controller v1.2.7** work, you must manually update `yt-dlp.exe`
     1.   ensure you have opened Lethal Company at least once since installing **Boombox Controller v1.2.7**
     2.   download the latest version of `yt-dlp.exe` from [github.com/yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp) [[direct download link](https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe)]
     3.   overwrite the existing `yt-dlp.exe` in `Lethal Company\BoomboxController\other` with the new one you just downloaded (see &ldquo;HOW TO INSTALL THE MODS&rdquo; for the shortcut to finding your `Lethal Company` folder)

## KNOWN ISSUES

last updated: `2025/12/29`

- **Boombox Controller v1.2.7** DOES NOT WORK AS IS, i.e. you have to fix it manually (see &ldquo;INFORMATION & RECOMMENDATIONS&rdquo;)
